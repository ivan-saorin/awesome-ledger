Additions

Momentic 12 NOV

End-to-end tests for web apps in Chromium and mobile apps on hosted iOS simulators and Android emulators, written as YAML that mixes preset steps with natural-language AI steps and run from a CLI locally or in CI. Includes Mo, an agent that explores a running app from a brief and reports findings with evidence.

judge-check 11 NOV

Checks whether an LLM judge can tell good output from bad by mixing planted decoys and known-good answers into its real inputs, then reporting how often the decoys pass. Zero dependencies, with an offline demo.

e2e 11 NOV

Open-source end-to-end testing framework for web and mobile apps, combining natural-language agent actions with locators and assertions.

★ ALSO IN AWESOME-ANGULAR

coverage 11 NOV

GitHub Action that compares LCOV and Go coverage reports against the base branch and posts per-file changes as a sticky PR comment.

Bite 11 NOV

Open-source CLI that checks whether recent "fixed" commits are really guarded by tests: it takes each fix back out and runs the project's own tests to see if any fail. Free mode needs no API key.

test-inventory 10 NOV

Extract declared tests, states and skip reasons from JavaScript and TypeScript source without running the suite, and compare saved inventories between revisions.

Buggregator 10 NOV

Local debugging server with a mock server (OpenAPI import), HTTP request capture and a fake SMTP server whose API waits for an email and extracts one-time codes.

blastradius 9 NOV

Test impact analysis for JVM projects (Maven, Gradle, JUnit 5) that runs only the tests affected by a change, using class dependencies recorded by a Java agent.

appfuzz 8 NOV

Fuzzes WebAssembly apps against a simulated backend and reports crashes, injection, n+1 queries and data leaks, with an exit code for CI.

AnalyticsProof 8 NOV

Regression tests for analytics tracking: replays recorded website journeys and reports which step lost a dataLayer event or GA4 parameter. Has a free plan.

ScopeHaven 7 NOV

Runs an AI agent's tasks against a local copy of your app, as different users, and checks whether "done" matches what the app's records show. Node CLI and GitHub Action, Apache-2.0.

Cerulion 7 NOV

Open-source robot runtime that records each run and re-executes supported native recordings against new code, exiting 1 with the name of the topic that changed, so a recorded robot run becomes a CI regression test.

★ ALSO IN AWESOME-RUST

evalship 5 NOV

GitHub App that finds flaws in your LLM evals, says on every pull request which evals a change broke and why, and finds prompt and model changes that win beyond chance.

llmdrill 4 NOV

Open-source CLI that runs your app behind a local fake of the Anthropic and OpenAI APIs, injects outages (529/503 overloads, 429 with retry-after, hangs, cut streams) and grades its retries, backoff, timeouts and failover.

Replay QA 4 NOV

Autonomous QA agent for web apps built on Replay's time-travel runtime recording and analysis. It explores an app from its URL, writes and runs Playwright tests, and delivers a root-cause analysis for each failure, backed by evidence from the recorded execution. Free tier, no credit card.

GenClass 4 NOV

Open-source browser library that reports race conditions in a web app while they happen (stale responses written over newer data, duplicate submits, failure storms) with a small on-device model. Its local MCP server re-runs a page with responses delivered in different orders to find races and replays one order to prove a fix.

bareenv 3 NOV

Runs a command once per environment combination (unset, empty, invalid) and reports the ones that break.

Bifurc 3 NOV

Local-first API client, mock server and traffic proxy for macOS, Windows and Linux, with a CLI for CI.

mendwright 2 NOV

Self-healing selectors for Playwright and Selenium in Python. Repairs a broken selector from a saved fingerprint of the element, asks a model only when that isn't enough, checks the repair on the live page and can write it back into your code.

Brume 2 NOV

Copies a subset of a PostgreSQL database to a test environment, pseudonymizing personal data and keeping foreign keys valid.

ghostwire 1 NOV

Open-source Linux tool that mocks ping, TCP connections, UDP errors and DNS per target address, with delay, jitter, loss and faults controllable live through an HTTP API; no proxy to point your program at, no root needed under exec.

Persqo 1 NOV

Runs AI personas (different ages, devices and patience levels) through a live web app in a real browser and returns ranked issues with screenshots and severity, plus ready-to-paste fix prompts for your coding agent. 3 free test sessions, no card; paid plans from $59/month.

Random IMEI Generator 31 OCT

Browser tool that generates 15-digit IMEI numbers with a valid Luhn check digit, exportable as text, JSON or CSV.

s3-test-server 30 OCT

S3-compatible server for tests that runs inside your Node.js test process or standalone via npx, and works with any SigV2/V4 client (AWS SDK v2/v3, AWS CLI, curl).

vibe-testing 29 OCT

Open-source MCP server and CLI that scans web app routes and forms, runs browser checks with Playwright, and produces HTML QA reports.

telegym 29 OCT

Load testing for Telegram bots: a drop-in Bot API mock plus a k6 extension that drives virtual users.

qarunbook 29 OCT

Free shared test runbook where testers record a pass or fail per platform with screenshots, and an issue marked fixed sends the check back for a retest.

postal-code-formats 29 OCT

Postal code formats, validation regexes and 9,000 real sample codes for 31 countries, with every regex tested against the samples in CI.

mailsocket 29 OCT

Inbox API that waits for an email OTP or magic link and returns it as JSON, with Python and TypeScript SDKs and an MCP server.

k6 29 OCT

Modern load testing tool, scriptable in JavaScript, with cloud and open-source options.

junit-collision-check 29 OCT

Offline Python CLI that detects duplicate test identities and conflicting outcomes across JUnit XML reports before CI report ingestion.

flight-recorder 29 OCT

Record every nondeterministic input your code reads (LLM answers, HTTP, database, clock, randomness) as one JSONL tape per request, then replay the tape against the real code offline, bit for bit, with the first divergence named. Open format with Python, Node, .NET, Go, Java and PHP implementations.

fieldtwin 29 OCT

Open-source, local, stateful twins of the Jobber and QuickBooks Online APIs for integration and AI agent tests, with checkpoints, rewind, and faults on demand.

fanout-check 29 OCT

Offline Python library and CLI that checks observed concurrency, overlap, and launch timing in explicitly grouped tool or agent calls.

cloudf.one 29 OCT

Rent a real Samsung Android phone in Singapore on a Singtel or M1 SIM and use it from a browser tab, to check how an app behaves for Singapore users. Manual use only, no Appium or scripts.

cloneproof 29 OCT

Scores how closely a website clone matches the original (pixels, layout, style, scroll motion) with Playwright and lists the exact differences.

check-proxy-tax 29 OCT

Zero-dependency CLI that samples a URL concurrently, then reports the 403 retry tax: usable-response rate and effective cost per 1,000 usable responses instead of the nominal per-1,000 price.

blastproof 29 OCT

Open-source AI agent that runs plain-English e2e tests in a real browser. It reads the pull request diff, runs only the tests for the pages that changed and can block the merge on a score. Runs locally or in CI with your own LLM key.

behave 29 OCT

Records how a command-line tool behaves (flags, stdin, exit codes, edge cases) as golden tests and replays them against another implementation, e.g. a Rust or Go rewrite.
