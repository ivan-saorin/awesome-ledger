Additions

worktrunk 30 AUG

Inspired by the oh-my-zsh git plugin and provides aliases and a few useful functions for working with worktrunk.

ssh-git-operations 30 AUG

Provides secure, authenticated git push/pull/fetch operations over SSH to remote machines using GitHub token authentication. Tokens are never persisted on remote machines.

histpop 30 AUG

Removes the last record from ~/.zsh_history. Useful right after running a command you don't want kept in your shell history (e.g. one containing a typo'd password or a temporary secret). Running histpop itself is also removed from history, so it leaves no trace.

git-branch 30 AUG

Augments git features, designed especially for users who prefer aesthetically pleasing branch naming conventions. It visually formats the current git branch name or commit hash, considering customisable variables like hiding status, maximum branch length, prefix, and suffix trimming, with an option to display git status.

cage 30 AUG

Adds command for age. It encrypts a plain file with a passphrase, decrypts an age file, and works out which from the file's own header.

psmon 29 AUG

Lightweight interactive process monitor using standard Linux utilities (ps, awk, lsof) with live watch mode, resource sorting, and tree-aware process killing.

mtsh 29 AUG

Multi-line prompt for multi-user and DevOps machines. Includes decorators for the date and time, the address of the interface that reaches the default route, CPU and memory use, the number of logged-in users, git branch and status, and the exit code and duration of the last command. No fonts are required.

dual-history 29 AUG

Keeps AI coding agent instructions (such as Forge's :-prefixed prompts) out of your main ZSH history by routing them to a separate file, intercepting every write path including the agent's own history insertions. Also turns Ctrl+R into an fzf interface switchable between All, Human and AI views, merged chronologically.

deja 29 AUG

Predicts the command you want to run from fuzzy matching, the current directory, and which command usually follows the previous one, then shows it as inline ghost text. Backed by a Go daemon.

ansible-fzf 29 AUG

A plugin that completes ansible-playbook tags and works with fzf-tab.
