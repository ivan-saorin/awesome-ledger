Additions

passwords 28 NOV

Passwords and 2FA (TOTP) codes from Apple Passwords / iCloud Keychain, straight from zsh, without leaking them into history, scrollback, ps, or clipboard managers.

omz-plus 28 NOV

pre-processes the builtin Oh-My-Zsh variables you're already using. By sourcing OMZ Plus! right before you source Oh-My-Zsh, it detects git-hosted plugins, handles cloning and symlinking, and then scrubs those variables back to the basics so that they are ready for oh-my-zsh to use

ltree 28 NOV

Works like the tree command, but truncates large directories by printing the first n files and summarizing the rest as ... m more files.

aurora 28 NOV

Minimal theme with the Dracula color palette. Includes decorators for username@hostname, current directory and git status.

zsh-editor-keys 23 NOV

Brings modern GUI editor keybindings to ZSH including Shift+Arrow char/subword/multi-line selection, cross-platform OS clipboard Cmd+C/X/V and Ctrl+Shift+C/X/V, Alt+A select all, Alt+Z undo/redo, and Shift+Enter newlines.

zsh-dropdown 23 NOV

Adds a flicker-free, prefix-only live completion dropdown for ZSH using DEC Mode 2026 synchronized redraws, automatic 24-bit/256-color themes, and ZSH 5.9 zasync self-healing.

wslpath 22 NOV

Convert a Windows path on the WSL ZSH command line by pressing Tab. Pasting or dragging a path into the terminal does not change it. The plugin uses WSL's wslpath and only replaces the path if the file or directory exists.

fzf-unified 22 NOV

A single managed source of truth for everything fzf inside ZSH: shell integration (Ctrl-T / Alt-C), history search (Ctrl-R), ripgrep live grep (Ctrl-G), Tab completion (fzf-tab, vendored) and the Up/Down arrow policy — one plugin instead of several loosely-coupled ones fighting over the same keybindings.

apathy 22 NOV

A terminal-to-agent zsh CLI that converts your pasted LLM prompts into actual invokes of harnesses like OpenCode, Claude Code and more. It manages to tell the difference between commands meant for your terminal, and prompts meant for your agent, as well as retain what you previously typed in your terminal.

shellsense (ThePubDoc) 18 NOV

IDE-style autocomplete for your terminal. Type a command and a list of what can come next opens under the word you are typing: subcommands, options, git branches, npm scripts, files and folders, each with a short description. Pick one with the arrow keys or keep typing to narrow the list.

hexagon 18 NOV

Minimalist ZSH theme based on geometry.

copylast 18 NOV

Reads the last command's output straight out of tmux's scrollback, so it's instant and you get exactly what you saw.

zest 17 NOV

Fig-style autocomplete popup for macOS. Shows subcommands, options, git branches and files with descriptions under the cursor in Terminal.app, VS Code and Cursor. Specs for 1,500 commands; new ones are a YAML file.

git-sweep 17 NOV

Small ZSH plugin for cleaning up Git branches and worktrees, with protected branch patterns, dry-run previews, optional interactive selection, and explicit remote cleanup.

worktrunk-herdr 11 NOV

glues Worktrunk (wt), AI coding agents (Claude Code, Codex, Pi) and herdr together.

gui-detach 11 NOV

Returns the prompt in interactive ZSH when a GUI app is launched on Linux, and leaves CLI tools in the foreground.

slowrc 9 NOV

Profiles your ZSH startup line by line, shows which lines of your .zshrc cost the most, and safely fixes the slow ones.

listview 9 NOV

Lightweight, zero-dependency ZSH plugin inspired by PowerShell's PSReadLine ListView. Displays real-time, non-intrusive unique history suggestions below your prompt as you type, navigatable using arrow keys.

Cue 9 NOV

Adds IDE-style command, option, and path suggestions to ZSH in a native macOS popup.

speedrunner 5 NOV

Speeds up the start of Python, Ruby, PHP and Node CLIs by forking them from a preloaded daemon. Its ZSH hook starts the daemon while you type the command name.

walh-shell 4 NOV

A fast, modern, and extensible Zsh (and Bash) plugin for instant terminal color theme switching that lets you instantly change your terminal’s color scheme with a single command.

sprout 4 NOV

Turn a Jira ticket into a clean git branch. One command. A short, descriptive name. Zero copy-pasting.

claude-guard 4 NOV

checks your egress IP before Claude Code starts. If the IP that claude.ai sees is not on your allowlist, claude stops and asks before it connects.

oops 2 NOV

Copies the last command and its output to the clipboard as a Markdown code block, with API keys and other secrets masked. Works in ZSH and bash. Installed as a Ruby gem (Ruby 3.3 or later).

fasd 2 NOV

A command-line productivity booster. Fasd offers quick access to files and directories for POSIX shells. It is inspired by tools like autojump, z and v. Fasd keeps track of files and directories you have accessed, so that you can quickly reference them in the command line.

claude-code 1 NOV

Adds ask and explain commands plus Ctrl+X (rewrite a natural-language request into a command, in place) and Alt+E (explain the typed command) widgets, built on the Claude Code CLI with tools and MCP servers disabled.

utm 31 OCT

Adds a single utm command on top of utmctl, the command line tool that ships with UTM, with tab completion for subcommands, virtual machine names and snapshot names, and a --wait that utmctl does not have.

tmux-inside 31 OCT

A drop-in replacement for the oh-my-zsh tmux plugin that makes the tmux aliases work from inside a tmux session: instead of trying to nest a session (which tmux refuses), they switch to the target session, creating it detached in the current directory if needed.

tab-start 31 OCT

adds starter entries to ZSH completion when you press TAB at a blank prompt. Uses fzf-tab to render those entries and provides grouping, fuzzy search, and selection.

sf-shortcuts 31 OCT

Short, predictable commands for the Salesforce CLI (sf), with tab completion for Apex classes, components (aura/lightning) and orgs.

curl-edit 31 OCT

Automatically open pasted cURL commands in an editor before executing them.

claude-sandbox 31 OCT

Points CLAUDE_CONFIG_DIR at a throwaway directory, so everything Claude Code reads and writes (settings, plugins, skills, history, credentials) stays inside that sandbox. Leave it, delete it, and your real setup is exactly as you left it.

aws-login 31 OCT

Provides an aws-login command that starts an AWS session that only the current terminal and its child processes can use.

SparkleBIOS 31 OCT

Draws a retro 1995 PC BIOS boot screen with real system facts and cached health checks when a new ZSH session starts.

friesent 23 OCT

Minimalist theme with decorators for username@host, an arrow that turns green or red based on the last command's exit status, the current directory, and git branch/status when inside a repository.

shtab 22 OCT

Automatically generate shell tab completion scripts for Python CLI apps, supports zsh, bash and tcsh.

suvadu 21 OCT

Shell history in local SQLite with directory, exit code and AI agent commands, with a ZSH widget for Ctrl+R and Up-arrow recall.
