Additions

paper-preflight 21 NOV

Checks every cited reference of a LaTeX project against Crossref, dblp, arXiv, DataCite, PubMed and OpenAlex records (existence, metadata mismatches, retractions) and reports undefined, duplicate and unused citation keys. Also available as a pre-commit hook, GitHub Action and MCP server.

overleaf-comments-export 21 NOV

Exports comment threads, replies and tracked changes to Markdown and JSON, and annotates the compiled PDF with highlights on the commented text.

latexci BibTeX tools 21 NOV

Browser-based .bib cleaner (removes duplicates, normalizes author names, escapes special characters) plus DOI, arXiv, PubMed and ISBN to BibTeX lookups, with no install and no account.

blacktex 21 NOV

Command-line tool that replaces commonly occurring LaTeX anti-patterns and cleans up your files.

betterbib 21 NOV

Command-line utility for improving your BibTeX files. Fetches information from online sources.

VerbTeX 21 NOV

LaTeX editor for the browser plus native Android, iOS, and Windows apps, with optional offline compilation on device. Freemium.

TikZJax 21 NOV

Renders TikZ diagrams to SVG in the browser by running TeX via WebAssembly.

Texpile 21 NOV

Free and open-source desktop editor that edits LaTeX visually (like LyX) or by source with IntelliSense, with local compilation and built-in Git. Also supports Typst and Markdown.

TeXlyre 21 NOV

Local-first, open-source browser editor for LaTeX with in-browser WebAssembly compilation, offline editing, and peer-to-peer collaboration via WebRTC.

TeXLive.net 21 NOV

Public compile service (used by LearnLaTeX.org) that turns an HTTP POST of a LaTeX document into a PDF.

SwiftLaTeX 21 NOV

pdfTeX and XeTeX compiled to WebAssembly, so you can compile LaTeX entirely in the browser or embed a TeX engine in a webpage.

SciTeX Writer 21 NOV

Manuscript compilation system with templates for manuscripts, revisions, and supplementary materials, plus figure, table, and citation handling, and an MCP server (38 tools).

SciTeX Cloud 21 NOV

Self-hostable online editor with AI assistant integration, figure/table/citation management, real-time collaboration, and an MCP server (29 tools).

RustFig 21 NOV

xfig rebuilt for Windows, macOS, Linux and the browser (no X server): LaTeX text typeset on the canvas, and every fig2dev export built in (TikZ, PSTricks, pict2e, pstex/pdftex, PDF, EPS, SVG). Reads and writes xfig's .fig files.

OpenAlex Local 21 NOV

Local OpenAlex database (284M scholarly works) with abstracts and semantic search for literature discovery, and an MCP server.

Murfy 21 NOV

Online LaTeX editor with real-time collaboration and built-in AI assistance for writing and error fixing. Freemium.

ModernTex 21 NOV

Native macOS LaTeX editor for academic writing, with synced source and PDF, plain-language error messages, submission-readiness checks, a visual TikZ designer and a table editor. Free 7-day trial, then a one-time $19.99.

Mathpix 21 NOV

OCR app and API that converts images and PDFs of printed or handwritten equations, tables, and text into LaTeX. Freemium; paid Pro and API.

MathPoint 21 NOV

PowerPoint and Word add-in that typesets LaTeX equations, TikZ figures and tables on a server, so no local TeX installation is needed. Freemium.

MathLive 21 NOV

Web component for editing and displaying math with LaTeX, including virtual keyboards and MathML/speech export.

LaTeX.Online 21 NOV

Cloud compiler that builds a PDF from a Git repository, a URL, or pasted TeX; also available as a self-hosted Docker image.

LaTeX Pro 21 NOV

LaTeX and BibTeX plugin for IntelliJ IDEA and other JetBrains IDEs, with project-wide navigation and refactoring, local builds, PDF preview with SyncTeX, and bibliography management. Paid ($30/yr, 7-day trial).

LaTeX Editor 21 NOV

Single-executable desktop editor with live PDF preview, two-way SyncTeX, LaTeX-aware spell checking, and one-key project snapshots written as a standard Git repository. Needs a separate TeX distribution.

Kroki 21 NOV

Unified HTTP API that renders text-based diagrams, including PGF/TikZ, to SVG, PNG, or PDF. Self-hostable.

KaTeX 21 NOV

Math rendering library made by Khan Academy focusing on fast load times. All output is processed as plain HTML instead of fixed images.

IguanaTex 21 NOV

PowerPoint add-in that inserts LaTeX equations typeset by your local TeX distribution and keeps the source with each shape, so you can edit and re-typeset it later.

Gummi 21 NOV

Simple GTK LaTeX editor with a continuously updating live preview pane.

CrossRef Local 21 NOV

Local CrossRef database (167M papers) with full-text search, impact factor data, Python API for bibliography enrichment, and an MCP server (15 tools).

CoCalc 21 NOV

Collaborative online LaTeX editor with real-time editing, TimeTravel history, and first-class SageTeX, PythonTeX, and Knitr support. Freemium.

BiblioAudit 21 NOV

Command-line tool to check, verify, and repair citations in BibTeX files across 12+ academic databases.

Biber 21 NOV

Modern bibliography processor for biblatex, with Unicode support and more flexible sorting than BibTeX.

BibTeX Style Examples 21 NOV

Example output of common BibTeX styles (BST files).

Aldine 21 NOV

Self-hosted online editor with real-time collaboration in which every project is a Git repository, with branches in the editor and push/pull to GitHub, GitLab and Gitea.
