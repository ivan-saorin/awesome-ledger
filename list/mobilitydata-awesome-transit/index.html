À portée de tram 27 NOV

Interactive travel-time maps for 25 cities in France, Belgium and Canada: pick a departure and the city is colored by travel time by tram and metro (optionally bus), with isochrones and a detailed itinerary. Times are computed from GTFS timetables (median ride times, waits from headways, branch-aware waits, published transfer times). Open-source on GitHub.

Veodyn 27 NOV

An open-source, self-hosted data platform for transit agencies: connectors for GTFS, GTFS Realtime, GBFS, TMDD and NTCIP 1203 feeds, historical capture into ClickHouse, a SQL editor, dashboards, a data catalog, and publishing of GBFS and GTFS Realtime feeds. Documentation and live demo.

TransCAPI 27 NOV

REST API for Great Britain bus and rail: departures and arrivals with live running (National Rail Darwin, BODS), live vehicles, disruptions matched to a route, and journey planning. Free tier.

GTFS to KML Converter 27 NOV

Free browser tool that converts GTFS shapes and stops into an organized KML for use in Google Earth.

gtfs-realtime-php 19 NOV

PHP bindings generated from the official GTFS-realtime protocol buffer specification, kept current with the spec and on a supported google/protobuf runtime. Available on Packagist as a drop-in replacement for lowa/gtfs-realtime-php.

InfraNode 12 NOV

Keyless REST (and MCP) API for 84+ German cities. Includes public-transport stops and live departures with real-time delays (DELFI/GTFS, HVV, VGN), alongside weather, air quality, traffic and roadworks. No API key.

GTFS·X 12 NOV

Fast, free, web-based GTFS editor. GNU licensed (GitHub).

GTFS Zone RT Visualizer 12 NOV

Static web application to analyze GTFS Realtime feeds. No login needed, fast, and transparent to the specification. Open-source (AGPL-3.0) on GitHub.

gtfs-osm-import 22 SEP

Java tool for importing GTFS data into OpenStreetMap, with conflict checks against existing OSM elements.

WMATA Exit Optimizer 22 SEP

Suggests which train car to board for the shortest walk to your destination station's exit on the WMATA Metro.

Transfer Hero 22 SEP

Realtime metro trip planning for WMATA that surfaces useful transfers.

RoutePress GTFS to GeoJSON Converter 22 SEP

Free, easy-to-use browser tool that converts GTFS shapes and stops into GeoJSON for use in ArcGIS, QGIS, and other GIS software. No installation required.

GTFS.guru 22 SEP

Rust-core GTFS validator that compiles to WebAssembly so feeds can be validated locally in the browser. Also ships desktop apps, a CLI, and Python bindings.

El Tracker 22 SEP

Realtime tracker for Chicago Transit Authority (CTA) Loop trains.

tods-validate 19 SEP

A Python validator and GitHub Action for TODS feeds, the operational overlay to GTFS covering crew runs, deadheads and vehicle assignments. Checks a feed against TODS v2.1.0, cross-checks the companion GTFS, and cites the spec section behind each finding. Also runs entirely in the browser via WebAssembly, so non-public operational data is not uploaded.

GTFS Analyzer 19 SEP

An open-source, local-first GTFS Schedule validator and quality analyzer written in Rust, available as a browser-based WebAssembly app, a Cargo-installable CLI, a Rust library, an npm SDK, and a CI/CD integration. It supports multilingual reports in Turkish, English, and Japanese, GTFS-JP v3/v4 profile validation, local browser processing without feed uploads, and additional specification, interoperability, accessibility, geographic, service, and operational quality analysis. Web app.

Bus RT Insights 19 SEP

Web-based transit analytics platform that turns GTFS and GTFS-Realtime data into automated KPIs, service delivery analysis, load profiles, and interactive maps and dashboards for any agency that has GTFS and GTFS-RT publicly available.

haltestelle.net 18 SEP

Live departure boards for every stop in Germany's VRR and VRS transit networks (Rhine-Ruhr / Rhine-Sieg, NRW), powered by the TRIAS realtime interface. Also shows live vehicle positions along each line and real-time elevator/escalator status — runs entirely in the browser, no app needed.

Croquis 18 SEP

An open-source R package and Shiny web application for transit sketch planning and GTFS production and editing. Users can upload an existing GTFS file or rapidly create one from scratch on an interactive map interface.
