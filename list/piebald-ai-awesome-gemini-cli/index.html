Additions

Dex 24 OCT

Gemini CLI extension with three Agent Skills for analytics engineering: explore a warehouse or DuckDB file read-only (profiles, PII flags, verified joins), author dbt models and semantic layers as reviewable diffs, and detect schema drift. Install with gemini extensions install https://github.com/exmergo/dex; needs uv.

Cooper Email 24 OCT

Email inboxes for agents with a hosted Streamable HTTP MCP server at https://cooperemail.com/mcp (OAuth or API key): Gemini CLI gets its own username@cooperemail.com address to send, read, and reply to mail and wait for replies or sign-up codes. The free plan includes 5 inboxes.

BlockVectra 24 OCT

MCP server for Robinhood Chain and multiple EVM networks. Connect over remote Streamable HTTP to discover chains and read docs without a key; RPC access follows each chain's policy, while Data API and account tools need an API key. Install: gemini extensions install https://github.com/blockvectra/mcp --ref main.

ppl 23 OCT

Personal CRM for humans with AI agents, with a hosted remote MCP server (OAuth) at https://withppl.com/mcp: Gemini CLI can look up contacts, log interactions, keep notes and set reminders about the people in your life. Free beta up to 1,000 contacts at https://withppl.com/register.

Super 23 OCT

Permission-gated superuser (sysadmin) MCP server that lets Gemini CLI check system status, disks and processes, run shell commands and read GitHub, behind a dangerous-command denylist, human approval gates, optional Cisco AI Defense and Duo authorization, and an append-only audit log. Python, local stdio; pip install superuser, then add the superuser command to your Gemini CLI MCP server config.

LitGravity 23 OCT

Adds lit to the Antigravity CLI (agy) so a request is planned, built with tests and recorded checks, reviewed, and closed with a handoff note.

Concord MCP 23 OCT

Local-first shared work-state MCP server (npx -y @concord-ai/concord-mcp) that lets coding agents coordinate on one repo through presence, file claims, messaging, handoffs and review packets. Works with Gemini CLI alongside Claude Code, Codex, Cursor and other agents. TypeScript, stdio, MIT.

Alchemist Coder 23 OCT

Open-source desktop app for Windows, macOS and Linux that indexes your Gemini CLI chats, together with Claude Code, Codex and Grok Build sessions, into one local, read-only full-text search. Running Gemini CLI over ACP inside the app is planned for its upcoming Pro edition; the free edition runs Claude Code and Codex on local models.

npmscan 22 OCT

npm supply-chain security: checks packages for malware, known vulnerabilities, typosquats, maintainer takeovers and risky install scripts before install, and audits package.json, lockfiles, SBOMs and PR dependency changes. 23 read-only tools, no API key, no signup. Remote Streamable HTTP, bundled with 5 skills as a Gemini CLI extension. Install: gemini extensions install https://github.com/salemalem/npmscan-mcp-plugin.

deed.page 22 OCT

Static hosting for agents with a remote MCP server that lets Gemini CLI publish an HTML file or static folder to a permanent public https://<slug>.deed.page URL and update it with the token it gets back. No account or API key for publishing; the companion Agent Skill is MIT (source). Remote Streamable HTTP. Add with gemini mcp add --transport http deed-page https://deed.page/mcp.

MCP servers, harness by harness (RigFit) 22 OCT

One MCP server (Context7) configured in Gemini CLI's settings.json alongside Claude Code, Codex CLI, OpenCode and goose, using each tool's documented syntax, with sources dated.

AutoHarness 22 OCT

Makes Gemini CLI (and Claude Code, Codex, Qwen Code) prepare before it builds: splits the task into areas of know-how, finds or writes a skill for each, checks the result against the original, and lets a fresh critic judge it. MIT.

Firecrawl 21 OCT

Official Firecrawl MCP server for web search, page scraping to markdown or JSON, and site crawling. The hosted server works keyless (rate limited) with search, scrape and parse; add an API key for crawl, map and the rest. The open-source server is MIT (source). Add with: gemini mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp.

ratchet 20 OCT

Code-size budget CLI (pip install ratchet-size): ratchet check refuses changes that grow source or test line counts past a ceiling, and only ratchet grant raises it. For Gemini CLI it is wired through a GEMINI.md instruction snippet (no hook); a CI check or git pre-commit hook enforces it.

laya-guard 19 OCT

Local guardrail with a BeforeTool hook for Gemini CLI (laya-guard install gemini-cli) that judges each shell command before it runs, using regex rules, protected paths, and a small on-device model. Blocked commands are denied; ones marked for review pass with a note. Also hooks into Claude Code, Codex, Cursor, and other agents. MIT.

US Watchlist Alerts 19 OCT

Agent Skills (SKILL.md) for a US stock watchlist: NYSE-aware, de-duplicated price alerts (levels, % moves, gaps, 52-week highs/lows, MA crosses, RSI, earnings) and morning/close briefs. Stdlib Python, no API key, never places trades. MIT. Install with npx skills add eli-alvarado/us-watchlist-alerts -y -a gemini-cli.

Gemini Safety Net 19 OCT

Gemini CLI extension that runs cc-safety-net as a BeforeTool hook. It blocks destructive Git and filesystem commands, and reads of secrets such as SSH keys and .env files, before Gemini runs the tool call. It parses the command, so wrapped forms such as bash -c are also checked. It is not a sandbox. MIT. Install with gemini extensions install https://github.com/kenryu42/gemini-safety-net.

ChatVault 19 OCT

Windows app that reads, searches and backs up your Gemini CLI chats across accounts, and continues any chat in Gemini CLI through a handoff file that carries the whole conversation.

agentvcr 18 OCT

Turns a Gemini CLI chat from ~/.gemini/tmp/*/chats (the JSONL format with rewinds and patches, or the older JSON files) into a self-contained HTML replay with a scrubbable timeline, diffs and terminal output, with API keys and other secrets masked locally first. Share it as a link through a secret gist on your own GitHub, embed it, export a Markdown transcript for a pull request, or have its GitHub Action comment the replay on agent PRs. Also reads Claude Code, Codex, Cursor and OpenCode. MIT, no dependencies. Run: npx agentvcr-cli.

SafetyCard 18 OCT

Safety-check MCP servers and AI agents against the OWASP agentic Top 10, and get the safest setup to run them. Install with npx skills add safetycard/safetycard --agent gemini-cli.

Kuudo Skills 18 OCT

Gemini CLI extension with 22 Agent Skills for Amazon sellers and advertisers: Sponsored Products and Brands audits, search-term mining, budget pacing, DSP and Amazon Marketing Cloud, listings, product images, repricing, FBA inbound, and profitability, built for Kuudo's hosted Amazon Ads and SP-API MCP servers. Price, budget, listing, and shipment writes are previewed and wait for your approval. Install with gemini extensions install https://github.com/KuudoAI/skills. PolyForm Shield 1.0.0 (source-available).

Thinking Methods 17 OCT

Curated Agent Skills (SKILL.md) for structured thinking on real decisions: five whys, pre-mortem, trade-offs, prioritization, six thinking hats, and twelve more methods plus a selector skill. Install as a Gemini extension (gemini extensions install https://github.com/ysskrishna/ai-agent-skills) or skills only (gemini skills install https://github.com/ysskrishna/ai-agent-skills.git --path skills). MIT.

SpaceApp 17 OCT

Self-hosted web workspace that runs Gemini CLI alongside OpenCode, Codex, Claude Code and other coding CLIs as side-by-side panes in persistent rooms, with MCP servers and managed browser panes. Install: npx --yes run-spaceapp@latest install. Source-available (BSL 1.1).

Google Hotels MCP 17 OCT

Search Google Hotels and Google Vacation Rentals from Gemini CLI: per-OTA nightly rates (Booking.com, Expedia, Agoda, Vrbo, Airbnb, Hotels.com and 10+ other providers), 3-month daily price calendars, amenities, nearby places and review topics. Local stdio server (3 tools) wrapping Apify Google Hotels actors; uvx --from "git+https://github.com/huynhtanan/google-hotels-mcp.git@v0.1.2" google-hotels-mcp.

AltoRank 17 OCT

Open-source SEO content software with a hosted MCP server: check whether search engines and AI crawlers can read a site, research keywords, read Google Search Console, and write sourced drafts into a person's review queue. No approve or publish tool. AGPL-3.0 and self-hostable (source). Remote Streamable HTTP with OAuth sign-in. Add with gemini mcp add --transport http altorank https://app.altorank.co/api/mcp.

session-handoff-kit 16 OCT

Agent Skill (open SKILL.md standard; installs into Gemini CLI with npx skills add alapha888/session-handoff-kit --agent gemini-cli) that ends a session with a structured handoff — goal state, decisions, files touched, open loops, next action — so the next session starts from facts instead of an over-full context. Also includes a context-hygiene checklist and a fill-in handoff template. MIT.

agy-powerline 16 OCT

Fast, configurable statusline for Antigravity CLI (agy), the successor to Gemini CLI, with real-time 5h/7d Gemini quota meters, pace markers, context usage, and interactive TUI editor. Zero dependencies, MIT.

Pethost 16 OCT

Hosting for Docker Compose projects with a remote MCP server (OAuth): Gemini CLI deploys a project, reads its logs and HTTP traffic, and rolls it back. Add it with gemini mcp add --transport http pethost https://mcp.pethost.dev/mcp.

MoltNode by Chord 16 OCT

Gemini CLI extension that connects two hosted MCP servers and a GEMINI.md context file: MoltNode for JSON-RPC reads on 31 blockchains, and Chord for DEX swap quotes and unsigned swap transactions on Base, Monad, BNB Chain, Avalanche, Arbitrum, Robinhood Chain and Arc, plus token boards, candles and wallet PnL. No API key; the agent's own wallet signs every transaction. MIT. Install via gemini extensions install https://github.com/tuantqse90/moltnode-mcp.

DC Hub 16 OCT

Live data for data-center site selection: a daily Data Center Power Index (DCPI) of where data centers can get grid power across 300+ markets, live grid feeds from the seven US ISOs, plus fiber, gas and electricity prices. Answers carry an as-of timestamp and a citation line. 94 tools, remote Streamable HTTP, free tier needs no key. Install: gemini extensions install https://github.com/azmartone67/dchub-mcp-server.

CurlShot 16 OCT

Screenshot API with a hosted MCP server: take_screenshot renders any web page in a real browser and returns the image (PNG, JPEG, WebP or PDF; full page, device presets, ad and cookie-banner blocking), so Gemini CLI can see a page, and list_devices lists the presets. Remote Streamable HTTP with a CurlShot API key; the server is closed source. Free plan of 100 screenshots a month, no card. Add with: gemini mcp add --transport http curlshot https://curlshot.com/api/mcp --header "Authorization: Bearer $CURLSHOT_API_KEY".

Check 16 OCT

Extension with a BeforeTool hook that checks each file write on your own machine before Gemini CLI makes it (and, on Linux, each shell command): files, folders, programs, git refs and packages it names must exist, and scripts must parse; what the machine proves wrong is blocked with the machine's message. Install: gemini extensions install https://github.com/golproductions/check-gemini. Paid, 14-day free trial.

brethof-brain 15 OCT

Gemini CLI extension for the hosted brethof-brain memory: with every prompt, the records that bear on it arrive before Gemini answers; a brief at session start; every turn archived; the same memory is shared with Claude Code, Codex and other agents. Needs a brethof-brain account (free plan). Install: gemini extensions install https://github.com/BrethofAI/brethof-brain-client.

PostEverywhere 15 OCT

Social media scheduler for Gemini CLI. Write, schedule and publish posts to Instagram, TikTok, YouTube, LinkedIn, X, Threads, Pinterest and Bluesky, and plan a content calendar. Install with gemini extensions install https://github.com/posteverywhere/gemini-cli-extension (posteverywhere.ai).

Latchkey 15 OCT

Self-healing GitHub Actions runners with a hosted MCP server for coding agents: read the CI failures self-heal could not fix (root cause, failing file, logs), check run status, dispatch workflows, and run commands on fresh ephemeral runners. Remote Streamable HTTP with a Latchkey API key; the server is closed source. Add with: gemini mcp add --transport http latchkey https://latchkey.dev/mcp --header "Authorization: Bearer $LATCHKEY_TOKEN".

Gemini CLI limits & pricing (QuotaBurn) 15 OCT

Source-linked guide to Gemini CLI daily request quotas, the free-tier change, and per-token API cost.

Aident Loadout 15 OCT

Hosted MCP server that gives Gemini CLI and other MCP clients one reusable setup for apps like GitHub, Slack, Gmail, Linear and Notion, plus 400+ expert-built Skills and built-in services (search, scraping, media generation) billed from one balance. Accounts are connected once in the browser and kept in Aident Vault, and every action is logged in Audit. Remote Streamable HTTP with OAuth sign-in; free pay-as-you-go start. Add with: gemini mcp add --transport http aident https://loadout.aident.ai/mcp.

tokenreceipt 14 OCT

Local CLI that reads Gemini CLI chat logs (plus Claude Code, Codex, OpenCode and other agents) and prints a till-style receipt of tokens per agent and model, priced at public API list prices. Exports SVG/PNG cards or JSON; no account, no upload, no dependencies. MIT. Run: npx github:henrikdukefoss/tokenreceipt.

magents 14 OCT

Gemini CLI extension, MCP server and CLI over the session transcripts Gemini CLI, Claude Code, Codex, Copilot CLI, Cursor, Grok and OpenCode already write. List and read other live sessions, hand off compact state, send into a specific chat, or spawn a headless session that replies through a shared inbox. Install: gemini extensions install https://github.com/abnegate/magents. Rust, MIT.

Wardlume 14 OCT

Locks the Mac's keyboard, mouse, and trackpad while Gemini CLI runs unattended, so progress stays visible but nobody can type into the session. Unlocks with Touch ID or Apple Watch; sandboxed with no network access.
